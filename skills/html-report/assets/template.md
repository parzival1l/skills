## Self-check

- [ ] Each heading is one full sentence without a final period.
- [ ] No sentence has more than 25 words.
- [ ] No "should", "may", "might", "could", "would", semicolons, "e.g.", "i.e.", or "etc.".
- [ ] One word for each meaning across the page.
- [ ] Each tag and eyebrow makes sense to a new reader.
- [ ] No number needs a disclaimer.
- [ ] Each chapter has a diagram or a table.
- [ ] Each diagram shows its final state without a click.
- [ ] No hex colors in SVG attributes. Both themes read.
